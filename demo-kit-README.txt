공모온 발표 키트 사용법
========================

이 폴더는 다른 PC에서 공모온을 그대로 실행하기 위한 전체 복사본입니다.
백엔드 .env(AI·이메일 설정)와 서버 데이터(계정·사용자 기록)까지 포함되어 있어,
이 폴더만 있으면 git이나 npm install 없이 실행할 수 있습니다.

실행 순서 (발표 PC에서)
-----------------------
1. Node.js 설치 확인
   - 명령 프롬프트에서 "node -v" 입력 → v20 이상이면 OK (이 키트는 v24에서 제작)
   - 없으면 https://nodejs.org 에서 설치

2. 서버 실행
   - start-dev.cmd 더블클릭
   - 콘솔 창 2개가 뜸: 백엔드(포트 3000) + 프론트엔드(포트 5173)
   - 창을 닫으면 해당 서버가 종료됨

3. 브라우저에서 http://localhost:5173 접속

주의 사항
---------
- 포트 3000·5173이 이미 사용 중이면 서버가 안 뜹니다. 기존 콘솔 창을 닫거나
  해당 포트를 쓰는 프로그램을 종료한 뒤 start-dev.cmd를 다시 실행하세요.
- AI 분석 키(backend/.env의 OPENAI_API_KEY)는 2026-10-21 23:59에 만료됩니다.
  발표가 그 이후라면 원래 PC에서 키를 재발급해 backend\.env를 교체하고,
  이 키트를 다시 만들어야 합니다.
- AI 분석은 인터넷 연결이 필요합니다 (LLM 게이트웨이 호출).
  연결이 없거나 키가 만료되면 데모(목업) 분석으로 자동 전환됩니다.
- 발표 당일에는 미리 한 번 실행해 아이디어 분석을 실제로 돌려 보세요.
  정상이면 "데모 분석" 문구가 아니라 실제 AI 분석 내용이 보입니다.

포함된 데이터
-------------
- backend/src/data/accounts.json   — 계정 1건 (김가을, 발표 시연용)
- backend/src/data/userdata.json   — 김가을의 찜·응모·아이디어·연습 노트
- backend/src/data/sessions.json   — 로그인 세션 (재로그인 불필요할 수 있음)
- backend/src/data/contests.json   — 자동 수집된 공모전 DB
- backend/.env                     — AI·이메일 설정

시연 계정 (발표용으로 꾸며 둔 데이터)
-------------------------------------
- 아이디(닉네임): 김가을
- 비밀번호: demo1234!
- 들어 있는 내역:
  · 응모 기록 3건 — 라디오 앱 아이디어 공모(수상), 물환경 공모(진행 중),
    외식경영 공모(탈락) → 대시보드 '도전 히스토리'에 수상·탈락·진행이 모두 보임
  · 찜 3건 — 모바일신분증·K-MEDI AI·울진 BI 공모전
  · 유형 검사 결과 — 문제 해결형(solver) 76%
  · 보관함 아이디어 1건 — "도서관 책 위치 안내 앱" (AI 분석 결과까지 저장돼
    '다시 보기'를 누르면 재분석 없이 바로 결과 화면이 복원됨)
  · 연습 노트 1건 — 예상 질문 2개 + 답변

시연 전 준비 (이 PC에서)
------------------------
1. start-dev.cmd로 서버 2개 실행 (포트 3000·5173)
2. 브라우저에서 http://localhost:5173 접속
3. '김가을 / demo1234!'로 로그인 — 서버 데이터가 이 브라우저로 복원됨
4. 시연 브라우저를 새 창으로 쓰는 것을 권장 (기존 캐시 영향 없음)
   · 이 PC에서 공모온을 쓴 적이 있으면 localStorage에 옛 기록이 남아 복원
     데이터와 섞일 수 있음 → 발표 전 개발자 도구(F12) > Application >
     Local Storage > http://localhost:5173 에서 'gongmo-on:' 항목 삭제,
     또는 시크릿 모드(InPrivate) 창을 쓰면 가장 깔끔함
5. AI 분석이 실제로 돌아가는지 보관함 '다시 보기'가 아닌 새 아이디어로 1회 확인
   (키 만료 시 데모 분석으로 조용히 전환됨 — 배지에 '데모 결과'가 보임)

시나리오 추천 (발표 대본 10번 슬라이드와 동일)
---------------------------------------------
1) 유형 검사 2~3문항 → 결과(76% 문제 해결형) → 아이디어 힌트로 이동
2) '도서관 책 위치 안내 앱' 보관함에서 다시 보기 → 분석 결과·추천 공모전·제안서 초안
3) 마이페이지 → 응모 기록의 결과 칩(수상/진행 중/탈락) → 대시보드 도전 히스토리
