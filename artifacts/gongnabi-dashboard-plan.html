공내비 현황 대시보드 계획서

공내비가 가진 데이터를 한 화면에 모아 보는 관제 페이지. 지금 응모할 수 있는 공모전, 내 활동 기록, 알림 발송 현황을 열자마자 한눈에 확인한다.

01

목표와 성공 기준

공내비의 데이터는 이미 4곳에 나뉘어 있다. 데이터 파일, 브라우저 저장소, 백엔드 알림 저장소. 대시보드는 이 흩어진 현황을 한 화면에 모아, 사용자와 운영자가 “지금 뭘 해야 하는지”를 열자마자 알게 하는 페이지다.

성공 기준

  • 3초 판독 — 첫 화면에서 마감 임박 공모전과 오늘의 할 일이 글자를 읽기 전에 눈에 들어온다 (마감일 순 정렬, 색으로 상태 구분).
  • 데이터 4종 전부 표시 — 공모전 데이터·아이디어 스파크·알림 발송 기록·내 활동 기록이 하나도 빠지지 않는다. 값이 없으면 빈 화면이 아니라 안내 문장을 보여 준다.
  • 의존성 0 — 차트도 라이브러리 없이 SVG로 직접 그린다. 기존 공내비와 같은 보라 액센트·카드 스타일이라 새로 익힐 것이 없다.
  • 거짓 정보 없음 — 화면의 모든 숫자는 실제 데이터에서 계산되고, 정적 데이터에는 “기준일”이 함께 표시된다.
02

폴더에 있는 네 종류의 데이터를 전부 사용한다. 읽기 전용이며, 대시보드는 기존 데이터 파일의 구조를 그대로 쓰므로 데이터 쪽 수정은 필요 없다.

  • 반응형 — 640px 이하에서 KPI 2열, 나머지 패널 1열로 재배치.
05

구현 단계

한 단계가 끝나면 바로 화면으로 확인하는 순서다. 전체 작업량은 5단계로, 단계 1–3만으로도 공모전 대시보드로서 동작한다.

  1. 집계 레이어data/dashboard.js — 마감일 병합·분야 묶기·localStorage 건수 / 확인: 집계 결과를 콘솔로 출력해 실제 값과 대조
  2. 페이지 뼈대/dashboard 라우트 · TopNav 아이콘 · KPI 4장 / 확인: 주소 직접 이동, 아이콘 표시, KPI 값이 집계와 일치
  3. 마감 타임라인 · 분포 차트마감일 순 목록 · 상태 색 · 가로 막대 / 확인: D-8·D-24·D-29·D-32 실측값과 일치, 7일 이내 빨간색 규칙
  4. 알림 통계 · 참고자료 패널백엔드 /stats + 알림·참고자료·스파크 패널 / 확인: 백엔드 켬·끔 각각에서 폴백 문구 동작
  5. 검증 · 마무리tsc 통과 · 320px 반응형 · 빈 상태 3종 · 기존 화면 회귀 / 확인: 07 검증 체크리스트 전 항목 통과
06

리스크와 대응

대시보드의 값은 결국 데이터의 신선도와 저장소 상태에 달려 있다. 예상되는 문제와 대응을 미리 정한다.

리스크대응
공모전 마감 지남 (정적 데이터)상단 기준일 배지 상시 표시. 마감한 공모전은 회색 “마감” 처리 후 목록 뒤로. 갱신은 mockData.js만 고치면 대시보드가 자동 반영 — 화면 수정 불필요
활동 기록이 브라우저마다 다름내 활동 패널에 “이 브라우저 기준” 문구 병기. 계정 간 공유되지 않는다는 점을 명시
백엔드 꺼짐알림 패널만 폴백 문구로 대체, 나머지 패널은 정적 데이터라 영향 없음 — 기존 알림 동기화의 “조용히 무시” 원칙과 동일
문자 발송이 log 모드만 있는 혼동건수마다 “log / 실발송” 배지를 붙여 테스트 기록과 실제 발송을 구분
값이 0인 화면이 텅 비어 보임KPI·목록마다 빈 상태 문구를 미리 정의 (“응모하면 이곳에 기록됩니다” 등)
07

검증 체크리스트

완성 판정 기준. 앞서 확인한 “거짓 정보 없음·출처 명시” 원칙을 대시보드에도 그대로 적용한다.

  • 모든 숫자가 실제 데이터에서 계산됨 — 화면에 박힌 샘플 숫자가 없다. 예시로 보여 주는 곳은 문구에 “예시”로 명시
  • 출처·기준일 명시 — 정적 데이터는 “2026-10-01 기준” 배지, 활동 기록은 “이 브라우저 기준” 문구
  • 거짓 정보 없음 — 공모전 제목·주최·마감일·링크는 실제 데이터 파일의 값 그대로
  • 빈 상태 3종 — 공모전 0건 / 활동 기록 0건 / 백엔드 꺼짐 각각 안내 문구로 동작
  • 기술 검증 — tsc 통과, npm run dev로 백엔드+프론트 동시 구동 확인, 320px에서 가로 스크롤 없음
  • 기존 화면 회귀 없음 — 홈·입력·결과·마이페이지가 영향 받지 않음 (TopNav 아이콘 추가 외 수정 없음)
일정. 단계 1–3이 핵심 경로다. 여기까지 완료되면 공모전 현황 대시보드로 이미 쓸 수 있고, 단계 4–5(알림 통계·검증)를 이어 붙인다. 각 단계는 이전 단계의 집계 모듈에 의존하므로 순서대로 진행한다.
